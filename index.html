The part we enjoy most: making it run itself.

Repetitive admin is where mistakes creep in. So we script it in PowerShell — the same steps, in the same order, every single time.

  • Nothing gets missedA script doesn't forget step four on a busy Friday afternoon.
  • Done in secondsJobs that mean hopping between four admin portals become one command.
  • Self-documentingThe script is a written record of exactly what changed, and why.
Offboard-User.ps1 — Riva Scripts
>_Offboard-User.ps1 Try it → 
# Offboard-User.ps1 — every step, in order, every time.
param(
    [Parameter(Mandatory)] [string] $User,
    [string] $Manager
)

Connect-MgGraph -Scopes 'User.ReadWrite.All' -NoWelcome
Connect-ExchangeOnline -ShowBanner:$false

# 1. Lock the door
Update-MgUser -UserId $User -AccountEnabled:$false
Revoke-MgUserSignInSession -UserId $User | Out-Null

# 2. Keep the mail, hand it to their manager
Set-Mailbox -Identity $User -Type Shared
if ($Manager) {
    Add-MailboxPermission $User -User $Manager -AccessRights FullAccess
}

# 3. Free up the licences
$skus = (Get-MgUserLicenseDetail -UserId $User).SkuId
Set-MgUserLicense -UserId $User -AddLicenses @() -RemoveLicenses $skus

Write-Host "✔ $User offboarded." -ForegroundColor Green
